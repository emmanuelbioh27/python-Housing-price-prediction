# Kumasi Ghana Housing Price Prediction

This project uses Python and machine learning to predict house prices in Kumasi, Ghana.

## Project Description

The project applies a supervised machine learning regression approach to a housing dataset adapted to the Kumasi, Ghana context.

The model uses housing characteristics such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Main road access
- Guest room
- Basement
- Hot water heating
- Air conditioning
- Preferred area
- Furnishing status
- Kumasi location

The target variable is the house price in Ghana cedis (GH₵).

## Machine Learning Workflow

The project follows these major steps:

1. Data loading
2. Data inspection
3. Exploratory Data Analysis
4. Data visualization
5. Categorical variable encoding
6. Train/test split
7. Feature scaling
8. Recursive Feature Elimination (RFE)
9. Ordinary Least Squares (OLS) regression
10. Variance Inflation Factor (VIF) analysis
11. Residual analysis
12. Model evaluation
13. New house price prediction

## Files

- `Kumasi_Ghana_Housing.csv` - housing dataset
- `Kumasi_Housing_Price_Prediction.ipynb` - complete Jupyter Notebook
- `Kumasi_Housing_Price_Prediction.py` - Python implementation
- `kumasi_house_price_model.pkl` - saved trained model

## Model Evaluation

The model is evaluated using:

- R-squared (R²)
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

The results describe the supplied learning dataset and should not be interpreted as a live property valuation system.
